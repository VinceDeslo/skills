How this review was produced

The PR was reviewed in one session, in four passes: orient (read the whole diff before judging it), correctness, fit, then verification — where every candidate finding was attacked against the code and dropped unless it held. Findings marked confirmed were traced in the code; those marked likely are unresolved and each says what would settle it.

The lists are capped at five per severity and ordered by consequence, so this is a top-five, not an exhaustive audit.
